## Featured Projects

### Perpustakaan ILKOM

A library management web application built with a modular frontend and backend architecture.

**Highlights:** Type-safe routing, server-state management, data tables, authentication, database integration, and library workflow management.

**Stack:** React, TypeScript, Vite, TanStack Router, TanStack Query, NestJS, Prisma, PostgreSQL.

[View Repository →](https://github.com/legacyditt/perpustakaan-ilkom)

### Booking Room Perpus Undana

A room reservation web application built with a decoupled frontend and backend architecture for managing university library room bookings.

Highlights: Interactive reservation calendar, session-based authentication, server-state management, file uploads, and reservation data exports.

Frontend: Next.js 16, React 19, TypeScript, TanStack Query, Axios, Tailwind CSS v4, shadcn/ui.

Backend: Express 5, Node.js, Prisma ORM, PostgreSQL, Better Auth.

Architecture: Feature-driven frontend and layered backend architecture.

[View Repository →](https://github.com/legacyditt/booking-room-perpusUndana)
